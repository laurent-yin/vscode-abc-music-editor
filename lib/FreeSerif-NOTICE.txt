Rebuilding the webfont
---------------------

Starting with the regular FreeSerif.ttf from GNU FreeFont 20120503 (the Debian
fonts-freefont-ttf package provides this font), use FontTools with Brotli:

python3 -m fontTools.subset FreeSerif.ttf \
  --output-file=lib/FreeSerif-chords.woff2 --flavor=woff2 \
  --unicodes='U+0000-024F,U+2000-206F,U+2100-22FF,U+266D-266F,U+1D12A-1D12B' \
  --name-IDs='*' --name-languages='*' --layout-features='*'

The subset includes Latin letters, accidentals and common chord symbols.
Other authored characters can use the browser's fallback font.
